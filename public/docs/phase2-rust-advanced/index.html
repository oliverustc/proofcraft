    前置条件

    完成 Phase 1 全部主题，能独立解释所有权与生命周期。

    阶段目标

    • 掌握 async/await 与 tokio 运行时，能编写异步网络程序
    • 理解 unsafe Rust 的使用边界，知道何时需要、何时应避免
    • 能编写声明宏（macro_rules!），理解过程宏的基本工作原理
    • 理解 Pin/Unpin、Send/Sync 等高级 trait 的语义
    • 能阅读并理解 arkworks / halo2 等 ZKP 库的源码结构（为 Phase 3 做准备）

## 动机

说明为什么 Rust 需要这个特性，解决了什么问题。
进阶主题往往有复杂的设计背景，动机比语法更重要。

## 核心机制

解释内部工作原理，不只是"怎么用"，而是"为什么这样用"。

## 使用边界与陷阱

明确该特性的适用场景和不该使用的场景。
unsafe 相关笔记必须包含"何时安全"的判断标准。

## 与 ZKP/区块链的关联

记录该特性在 arkworks / halo2 / polkadot-sdk 中的实际应用场景，
建立进阶学习与研究目标的连接。

    写作原则

    • 重点解释"为什么"：进阶特性通常有不直觉的设计，动机比 API 更重要
    • 代码必须能运行：async 示例需标注所用 tokio 版本
    • 记录源码索引：如果某个概念在 arkworks/halo2 中有对应实现，记录文件路径和行号
    • LLM 辅助提示词模板： 
      我在学习 Rust 的 <主题>，已经理解了 <前置知识>。
请从底层实现角度解释 <具体问题>，
并给出一个在 ZKP 或区块链库中实际出现的使用场景。
