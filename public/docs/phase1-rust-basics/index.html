    Rust 基础

    Phase 1 · Rust 基础

    Phase 1 · Rust 基础

    阶段目标

    完成本阶段后，应能做到：

    • 理解所有权、借用、生命周期的核心规则，能在不看文档的情况下解释原因
    • 熟练使用 struct、enum、trait、泛型、迭代器、闭包
    • 能独立编写 300 行以内的 Rust 程序，不依赖 clone 或 unwrap 规避编译错误
    • 完成 rustlings 全部练习
    • 完成 rust-by-practice 基础章节（所有权 / 类型 / 模式匹配 / 错误处理）

    参考资料（对应 submodule 路径）

    资料 路径 用途
    The Rust Book rust/book/ 主线教材，逐章精读
    Rust 语言圣经 rust/rust-course/ 中文补充，攻克难点
    Rustlings rust/rustlings/ 交互式练习，每节即时验证
    Rust By Practice rust/rust-by-practice/ 章节配套题，巩固进阶
    Comprehensive Rust rust/comprehensive-rust/ 查漏补缺，快速定位薄弱点

    主题进度

    按顺序学习，完成后打勾。

    核心概念

    • 变量、数据类型、函数、控制流
    • 所有权（Ownership）
    • 借用与引用（Borrowing & References）
    • Slice 类型
    • 结构体（Struct）
    • 枚举与模式匹配（Enum & match）
    • 模块系统（mod、use、pub）
    • 常用集合（Vec、HashMap、String）
    • 错误处理（Result、Option、?）
    • 泛型（Generics）
    • Trait 与 Trait 对象
    • 生命周期（Lifetimes）
    • 闭包（Closures）
    • 迭代器（Iterators）
    • 智能指针（Box、Rc、RefCell）
    • 并发基础（thread、Mutex、Arc）

    笔记结构模板

    每篇笔记遵循以下结构：

    # <主题名>

## 核心规则

用 1–3 条简洁的规则总结该主题的本质。
避免照抄文档，用自己的话表述。

## 为什么这样设计

解释 Rust 这样设计的动机（内存安全 / 零成本抽象 / 编译期保证等）。
这一节促使深度理解，而非死记硬背。

## 最小示例

给出能直接运行的最小代码片段，聚焦于该概念本身。

​```rust
// 示例代码
​```

## 常见错误模式

列出该主题下自己遇到过或容易犯的编译错误，附编译器报错信息和修正方式。

## 与其他概念的关联

记录该主题与其他已学主题的关联，构建知识网络。

## 练习记录

记录 rustlings / rust-by-practice 中对应练习的编号，以及做题时的卡点和解法思路。

    写作原则

    • 不抄文档：用自己的语言重新表述，哪怕不够精确，也比复制粘贴更有价值
    • 代码必须能运行：所有代码片段在写入笔记前先在本地编译通过
    • 记录困惑而非只记结论：曾经困惑的地方往往是最有价值的笔记内容
    • LLM 辅助提示词模板： 
      我在学习 Rust 的 <主题>，遇到了以下问题：<问题描述>
请用类比 + 最小可运行示例来解释，不需要引入超出当前主题的新概念。
