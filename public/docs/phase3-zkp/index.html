    Phase 3 · 零知识证明

    Phase 3 · 零知识证明

    前置条件

    • 完成 Phase 1 & 2，能读懂 Rust 库源码
    • 具备基础数学背景：线性代数、抽象代数（群/域）
    • 了解椭圆曲线密码学基本概念

    阶段目标

    • 理解 ZKP 的基本定义（完备性、可靠性、零知识性）
    • 掌握 R1CS 约束系统的构造方式
    • 能用 arkworks 编写并验证一个简单的 Groth16 电路
    • 理解 PLONKish 算术化，能用 halo2 编写自定义电路
    • 了解 FRI 协议原理，理解 Plonky3 的设计定位

    参考资料

    zcash/halo2 zkp/halo2/ PLONKish 电路，工业级实践

    主题进度

    数学基础

    • 有限域（Finite Field）运算
    • 椭圆曲线群与配对（Pairing）
    • 多项式承诺方案（KZG / FRI）

    ZKP 协议理论

    • Interactive Proof 与 SNARK 定义

    • Groth16 协议（Setup / Prove / Verify）
    • PLONK 算术化与置换证明
    • PLONKish 与 lookup argument
    • FRI 协议与 STARK 基础

    arkworks 实践

    • ark-ff：有限域元素操作
    • ark-ec：椭圆曲线操作
    • ark-relations：R1CS 约束系统定义
    • ark-groth16：Groth16 证明生成与验证
    • 编写第一个完整电路（如：证明知道某哈希原像）

    halo2 实践

    • halo2 电路模型（Advice / Instance / Fixed columns）
    • Region 与 Selector 机制
    • 自定义 Gate 编写
    • Lookup Table
    • 编写第一个 halo2 电路

    协议笔记模板 

    # <协议名>

## 解决的问题

明确该协议要证明什么，以及为什么朴素方法不够好。

## 协议流程

用伪代码或步骤列表描述 Setup / Prove / Verify 三阶段。

## 安全性假设

列出该协议依赖的密码学假设（如 q-SDH、Fiat-Shamir 等）。

## 实现：代码实践

记录用 arkworks / halo2 实现该协议的关键代码，附完整可运行示例链接。

## 局限性与适用场景

记录该方案的 proof size、verify time、是否需要可信设置等关键参数。

    写作原则

    • 数学公式用 LaTeX：保持符号与文献一致，方便对照论文
    • 每个协议附"我能用它证明什么"：从应用视角驱动理解
    • 代码与协议双向对照：阅读 arkworks/halo2 源码时，记录代码行号与协议步骤的对应关系
    • 记录困难：ZKP 学习曲线陡峭，卡住的地方比顺利的地方更值得记录
    • LLM 辅助提示词模板： 
      我在学习 <协议名>，已理解 <前置概念>。
请用具体的数值例子（小的有限域，如 F_7）演示一遍 <具体步骤>，
然后说明 arkworks 中对应的代码在哪里实现了这一步。
